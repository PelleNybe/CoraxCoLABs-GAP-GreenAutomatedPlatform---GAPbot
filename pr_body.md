🎯 **What:** The Dockerfile was configured to run the container as the root user by default.
⚠️ **Risk:** Running containers as root poses a significant security risk, especially in Edge AI environments where devices can be accessed physically. If an attacker exploits a vulnerability in the application, they could gain root privileges inside the container, which might allow them to break out to the host system.
🛡️ **Solution:** Created a non-root user (`gapuser`), updated ownership of the `/gap_ws` workspace, and explicitly switched to this non-root user via the `USER` instruction before executing the ENTRYPOINT.
